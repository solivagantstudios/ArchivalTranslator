# ArchivalTranslator
An AI-powered translator Svelte plug-in for InDesign and Photoshop. With features like up and download from and to Weblate, Auto-ID, and using Ollama for your models.
Made this plug-in for media with a lot of text that is going to be translated to primarly English for archival purposed, hence the name of the plugin. It can however be used for various translation jobs. The Weblate integration is done to have a central place for translations, and auto-translations through machine learning/ai on their. However it also supports direct translations per text layer.
The ID-system is mainly for Weblate, and consists of [page-number][First following letter in the alphabet], for example: page 245 and the third text field would be ID 245C. I chose this system to be easily recognizable. The destinction between numbers and laters makes it visually easier to see which text field it is. Text fields are scanned from top left to bottom right, so if 2 text layers are on the same height of the page, the most left one will be having an ID first.
